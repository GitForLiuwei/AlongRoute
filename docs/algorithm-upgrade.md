# 算法改造记录（2026-11-04）

## 已实现

- 从地图返回的最多三条接近最快时间的司机路线发现候选，沿线搜索中心最多60个；每次POI搜索25条并展开返回的入口子POI。
- 候选按路线区段分配名额，不再按35米直线距离合并道路两侧位置，也不按站中心300米直接删除候选。最多48个候选分批精算。
- 司机使用一次A→P→B途经路线；要求P附近的路线几何连接及具名道路信息。到P时间按供应商路段耗时与段内进度估算，不具备车道级停靠认证。
- 分开返回额外驾驶和停靠耗时，界面总时间上限仍包括停靠；路边暂按90秒、停车场180秒估算。
- 公交按明确类型识别，避免“地铁接驳公交”被当作地铁。缺少入口、接驳分段时间或不支持的铁路/出租车混合段不静默通过。
- 严格核验实际首乘站台/入口步行≤300米。端点误差从30米收紧到5米，误差距离和时间纳入估算；仍不能据此证明小缺口跨越障碍时可通行。
- 到站步行替换原公交接驳段，总步行与时间统一核算；新步行比原段慢超过30秒时拒绝复用原时刻方案，避免明显错过接续。较小差异只作保守估时，并不保证具体班次可达。
- “省时间”按全程时间排序；“省费用”只考虑比当前最快候选至多慢15分钟的结果。费用未知不当作零或可信固定报价。对有完整数据且各方面更差的候选进行淘汰，对相同入口和行程去重。
- 打车增加明确标注的5分钟接车假设，未接入真实车辆供给；等待可能更久。
- 尝试计算A直接去C、随车到B再去C两个对照，给出差异及对照更优提示。对照同样受接驳约束和数据完整性限制；缺失时不声称中途下车更优。
- 沿途搜索30秒、精算及对照60秒、HTTP总期限110秒；地图调用250次预算。支持取消并终止后端任务，保留已完成候选；区分服务失败与无结果。
- 前端结果绑定输入快照；输入变化取消旧请求并标记过期，旧请求不可覆盖当前上下文。地图及偏好标签来自同一快照。结果5分钟后提示重算。
- 出发时间明确为中国时间；地点搜索失败可见；复制内容含司机终点、乘客指定接驳点坐标及线路。

## 数据与功能边界

尚未接入道路侧/车道/路缘停靠数据库、实时禁停与入口开放、公交实时候车、网约车供给和报价、GPS行驶进度。所有自动产生的位置仍是待核实候选，不能自动升为“已验证可停”。地图途经路线验证不替代现场停靠核实。

当前用于出发前规划。行驶中淘汰车后点、导航软件精确交接指定道路侧、人工核实落客点库，需要后续数据及定位能力。长路线和达到预算的搜索不承诺全局最优；search_complete只表示本次保留候选是否完成计算。

## 验证

回归测试覆盖300米边界、总步行分段替换、缺失接驳时间、较慢步行导致原时刻失效、公交类型识别、具名道路要求、连续途经路线及P附近断点、地图步行吸附误差、最快偏好和省钱耗时预算。

广州真实接口行程（广州塔→司机广州东站、乘客广州南站，公共交通、司机增加总时间上限10分钟）取得2个推荐，首乘到站核验步行分别106米和266米；该次未取得可用对照，不能据此声称优于直接出行。真实接口验证仅确认数据链路及约束通过，不替代实地上下客检查。


## 高速出口与近站规则更新

- 仅公共交通选项有首乘实际站台/地铁入口步行≤300米的硬限制。只选打车不会调用公交规划；同时选择时，两种方式分别保留候选搜索名额，每个位置独立验证两种方式，公交失败不删除可用打车选项。
- 公交搜索增加车辆驶向站点的实际路线末端候选：公交站附近40/70/120米，地铁入口附近10/30/70米。距离是生成候选的偏移量，最终仍核验真实步行距离和驾车可达性，不把站台坐标直接视为可停靠点。
- 第一批成功方案出来后，再围绕方案实际使用的至多两个首乘站点补找更近位置。相同费用、换乘不增加、全程时间相差不超过2分钟且综合分接近时，优先实际到站步行更短的方案。
- 高速/快速路主线不再作为下客地点周边搜索中心；道路名称与导航说明共同识别受限路段，立交、匝道不直接作为停靠位置。
- 高速沿途分散搜索出口POI，同时提取原路线转入普通道路的区域。出口是发现区域的锚点，不作为下车点。优先原路线驶出区域，同时允许在用户耗时上限内提前驶出。
- 高速附近的下客候选需关联出口，完整请求A→驶向出口的沿途点→出口→P→B；检查途经顺序及P附近道路条件，额外时间包括后续驶向B和停靠，不能只计算驶出高速这一段。
- 出口发现与搜索仍有预算，不能保证覆盖所有出口；POI位置、道路侧和现场停靠条件仍需确认。没有出口或无法证明途经连接时，过滤该高速附近候选，不猜测出口可用性。
- 起点已在高速等受限路段时，不再把“从A立即换乘”当成可执行对照。

本轮真实接口验证：广州公交行程取得3个候选，首乘到站步行33米、41米、160米；以高速主线坐标为起点的高速打车行程取得2个有出口关联的候选，均无需公交站或300米接驳数据。验证只覆盖接口路线及约束，不代表现场停靠已核实。


## 公共交通详细乘坐方式

公共交通选项新增按行程顺序排列的 transit_steps：到首站步行、每段公交或地铁、换乘步行、末站到乘客目的地步行。每段乘车展示线路及区间标识、开往方向、上下车站、乘坐站数、途经站、已返回的进站口与出站口；步行展示距离、耗时和可展开指引。供应商只返回中间途经站数时，乘坐站数按该数字加一；缺失方向和站数时明确提示，不自行猜测。

首段步行的展示距离、耗时及指引与300米核验使用同一路径。独立步行核验替换原路径时清除旧路径指引。推荐面板切到“公交 / 地铁”后直接显示乘坐步骤，对照方案也可展开查看。打车面板不显示公交步骤，旧结果缺少新字段时提示重新计算。
